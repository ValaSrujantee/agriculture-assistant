Technical Rigor

Logical Separation of Concerns

A maintainable, scientifically grounded 4-tier decision-support architecture.

1. Machine Learning Engine

Role: "Which crop is predicted?"

Trained Decision Tree Classifier evaluates multivariate non-linear agronomic boundaries (N, P, K, Temp, Humidity, pH, Rainfall) to rank candidate crops.

2. Agronomic Rule Engine

Role: "Are conditions suitable or concerning?"

Evaluates soil nutrient thresholds, warns on extreme drought, excessive rainfall, thermal stress, and seasonal incompatibilities.

3. Curated Knowledge Base

Role: "What agricultural guidance should be shown?"

Provides actionable advice on water management, irrigation stages, fertilizer schedules, and pest scouting without unscientific claims.

4. Interactive SaaS Dashboard

Role: "How should the information be presented?"

Responsive UI with Chart.js analytics, dark mode support, demo farm presets, and printable advisory summaries.
