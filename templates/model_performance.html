🔄 Retraining the ML Model

The system provides a standalone CLI script to retrain the Decision Tree model on new agronomic datasets.

# Run the training script from the project root:
python train_model.py

The script automatically re-evaluates accuracy, computes feature importances, saves the serialized model (crop_model.pkl), and updates this metadata page.
